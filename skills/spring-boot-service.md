Maintain strict layered architecture: Controllers handle HTTP transport and routing, Services coordinate business logic and transactions, and Repositories handle data persistence. Never leak persistence entities across the API boundary; map incoming requests and outgoing responses through dedicated DTO records or classes. Validate request DTOs declaratively using Jakarta Bean Validation (@Valid, @NotNull, @Size); do not scatter manual validation logic across services. Apply @Transactional at the service layer, marking read-only query operations with readOnly = true; keep external network I/O and slow operations out of database transaction blocks to prevent connection pool exhaustion. Handle errors centrally with @RestControllerAdvice; map specific domain and validation exceptions to structured responses (such as ProblemDetail) with appropriate HTTP status codes, and never leak internal stack traces or database errors to callers. Never hardcode credentials, API tokens, or secrets; bind external environment configuration via typed @ConfigurationProperties with validation. Structure tests into targeted slices: use @WebMvcTest for controllers with mock service beans, @DataJpaTest for persistence queries, and @SpringBootTest for end-to-end integration flows. Verify test execution through JUnit reports.
