Follow Modern Android Architecture with unidirectional data flow: UI emits user events and renders immutable state. Hoist state to ViewModels or parent composables; make composables stateless by passing an explicit state object and event lambdas ((Event) -> Unit). Never mutate state or trigger side effects during composition. Confine side effects to Compose effect handlers: use LaunchedEffect with explicit keys for coroutines, rememberUpdatedState for stable callbacks, and DisposableEffect with onDispose for listener cleanup. Expose UI state from ViewModels using StateFlow with stateIn; collect state in composables using collectAsStateWithLifecycle to avoid background resource drain. ViewModels must remain free of Context, android.* UI imports, and direct View references. Use structured concurrency with viewModelScope; forbid GlobalScope and runBlocking in production code. For navigation, use type-safe destinations, pass minimal primitive IDs instead of complex parcelables, and hoist navigation actions to screen-level event handlers. Write unit tests for ViewModels and repositories using TestScope, StandardTestDispatcher, and Turbine for Flow verification; write UI tests using Compose test rules and Roborazzi screenshot verification.
